# Evaluation & Metrics

## Key Metrics

- **Recall of Resolvable Persons**: 1.00 at 35m, 50m, 70m (calibration artifacts in `base/artifacts/`).
- **Geotag Error**: Mean <30m, worst case bounded by reported sigma.
- **Coverage**: Probability-weighted, not boolean.
- **Link Performance**: Packet success, delivered bytes, coalesced updates.

## Calibration Artifacts

Generated by `base/scripts/eval_detector.py` (derived from original SIH scripts). See:
- `base/artifacts/detector_aimed.json`
- `base/artifacts/mission_flood.json`

## Failure Modes Documented

See `DOCUMENTATION/PROJECT_PLAN.md` for the full list of failure modes paid for by the original project (tilt inversion, NED/body rotation, centimetre/metre confusion, etc.).

## Simulation Validation

The `emulator/` folder allows independent validation of:
- Thermal physics against simulated environments.
- AI performance under smoke, night, flood conditions.
- Dashboard response to simulated detections.
